2. a. As a member of Blue team experts in Monitoring and Technical Support of a medium sized company, you have been asked to assess the security posture of the internal network. Use Nmap for network discovery, Port scanning, Service version detection and vulnerability detection. Then Document your findings, including the identified vulnerabilities, their severity levels. 

Nmap ("Network Mapper") is a free and open source utility for network discovery and security auditing. Many systems and network administrators also find it useful for tasks such as network inventory, managing service upgrade schedules, and monitoring host or service uptime. 

It uses raw IP packets in novel ways to determine what hosts are available on the network, what services (application name and version) those hosts are offering, what operating systems (and OS versions) they are running, what type of packet filters/firewalls are in use, and dozens of other characteristics. It was designed to rapidly scan large networks, but works fine against single hosts. 

nmap <IP>→ Performs a basic scan of the target IP to list open ports and services.

sudo nmap -v <IP>→ Runs a detailed (verbose) scan showing progress and extra information.

nmap --open <IP>→ Displays only ports that are open, hiding closed or filtered ones.

nmap -A <IP>→ Aggressive scan: detects OS, services, versions, and possible vulnerabilities.

nmap -p 80 <IP>→ Scans only port 80 (commonly used for web servers).

nmap --top-ports 10 <IP>→ Scans the 10 most commonly used ports on the target.

nmap -O <IP>→ Detects the operating system running on the target machine.

nmap -sV <IP>→ Detects service versions (e.g., Apache 2.4, SSH 8.2) on open ports.

nmap -sS <IP>→ Performs a TCP SYN scan (stealthy and fast) to find open ports.

nmap -sT <IP>→ Performs a full TCP connect scan (less stealthy but reliable).

nmap -sU <IP>→ Scans for open UDP ports (used by DNS, SNMP, etc.).

nmap -sO <IP>→ Scans for supported IP protocols (like TCP, UDP, ICMP) on the target.

1. Start Kali Linux and Metasploitable2 VMs, then obtain the target IP.
2. Open terminal in Kali and run basic scans:
   - nmap <IP>
   - sudo nmap -v <IP> (verbose)
   - nmap -V <IP> (version)
   - nmap <IP1> <IP2> (multiple hosts)
   - nmap <network-range> --exclude <IP> (exclude host)
   - nmap --open <IP> (show only open ports)
   - nmap -A <IP> (aggressive scan)
   - nmap -sA <IP> (check if packets are filtered)
   - nmap -p 80 <IP> (specific port)
   - nmap --packet-trace <IP> (trace packets)
   - nmap --top-ports 10 <IP> (top ports)

OS Detection:
   - nmap -O <IP>
   - nmap -v -O <IP>
   - nmap -O --osscan-guess <IP>

Service Detection:
   - nmap -sV -O <IP>
   - nmap -sV --version-trace <IP>

Advanced Scans:
   - nmap -sS <IP> (TCP SYN)
   - nmap -sT <IP> (TCP Connect)
   - nmap -sU <IP> (UDP)
   - sudo nmap -sN <IP> (TCP Null)
   - sudo nmap -sF <IP> (TCP FIN)

Custom Scans:
   - nmap -sS --scanflags SYNFIN -T4 www.google.com
   - nmap -sO <IP> (protocol scan)
   - nmap --send-eth <IP> (Ethernet packets)
   - nmap --send-ip <IP> (IP packets)

3. Imagine a legal firm handling contracts for clients remotely. Let’s say a client, Mr. John, needs to sign a contract for a property purchase. how could Cryptool be applied to digitally sign a contract document, authenticate its validity, and ensure the secure storage of both the digital signature and the original document? Demonstrate the use of digital signatures using cryptool by performing following things: 
a) Creation of signature b) Storing the signature c) Verifying the signature 
RSA (Rivest–Shamir–Adleman) is an asymmetric encryption algorithm that uses two keys:
- Public key → encrypts data or verifies signatures.- Private key → decrypts data or creates signatures.
1. Key Generation:
   - Choose two prime numbers p and q.
   - Compute n = p × q and φ(n) = (p−1)(q−1).
   - Select e such that 1 < e < φ(n) and gcd(e, φ(n)) = 1.
   - Compute d so that e × d ≡ 1 (mod φ(n)).
   - Public key = (e, n), Private key = (d, n).
2. Encryption:
   - Convert message M to a number.
   - Ciphertext C = M^e mod n.
3. Decryption:
   - M = C^d mod n → original message recovered.
In Cryptool2:
- Generate RSA key pair (2048 bits).
- Encrypt file using public key.
- Decrypt using private key.
- Create digital signature (RSA + SHA‑256) and verify with public key.
Purpose:
- Ensures confidentiality, authenticity, integrity, and non‑repudiation.

🔧 Minimal snort.conf Setup (First Time)
Open the file:
bash
sudo vi /etc/snort/snort.conf

Add or check the following key lines:
bash
# Define the HOME and EXTERNAL networks
ipvar HOME_NET 192.168.111.133/24
ipvar EXTERNAL_NET any

# Define rule path
var RULE_PATH /etc/snort/rules

# Include rule files
include $RULE_PATH/local.rules
include $RULE_PATH/icmp.rules

📄 local.rules (Custom Rules)
Create or edit /etc/snort/rules/local.rules:
bash
# Detect ICMP ping attempts
alert icmp $EXTERNAL_NET any -> $HOME_NET any (msg:"Varsha - ICMP Ping Detected"; sid:5889; rev:1;)

# Detect FTP connection attempts
alert tcp any any -> $HOME_NET 21 (msg:"FTP Attempted"; sid:60001; rev:1;)

# Detect SSH connection attempts
alert tcp any any -> $HOME_NET 22 (msg:"SSH Attempted"; sid:60002; rev:1;)

📄 icmp.rules (Separate ICMP Rules)
Create /etc/snort/rules/icmp.rules:
bash
# Detect ICMP echo request (ping)
alert icmp any any -> $HOME_NET any (msg:"ICMP Echo Request Detected"; sid:70001; rev:1;)

# Detect ICMP echo reply
alert icmp $HOME_NET any -> any any (msg:"ICMP Echo Reply Detected"; sid:70002; rev:1;)

sudo snort -T -c /etc/snort/snort.conf
